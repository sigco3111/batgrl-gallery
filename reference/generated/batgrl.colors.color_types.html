type batgrl.colors.color_types.AHexcode = str#

A hexcode string for a 32-bit color. Six or eight hex digits optionally preceded by “#”, e.g., “#abcd1234”. If eight hex digits are given, the last two digits specify the alpha channel, otherwise, the alpha channel value defaults to 255 so that the six digit string "#abc123 is equivalent to "#abc123ff".
